# NIST CSF 2.0 — Web Application Security Assessment Checklist

This repository provides a structured checklist for assessing web applications against the NIST Cybersecurity Framework (CSF) 2.0.  
It covers all six CSF functions: Govern, Identify, Protect, Detect, Respond, and Recover.

## 📌 Features
- 50+ checklist items mapped to NIST CSF 2.0
- Evidence references for audits (policy docs, scan reports, contracts)
- Status tracking (Yes / No / Partial / NA)
- Reusable template for AppSec teams

## 🚀 Usage
1. Open the Excel file `NIST_CSF_AppAssessment_BhanuG.xlsx`
2. Select status for each control (Yes, No, Partial, NA)
3. Add remarks and evidence references
4. Use summary sheets to track overall security posture
